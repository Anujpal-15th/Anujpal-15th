## Featured projects

### [CodeSense AI](https://github.com/Anujpal-15th/codesense-ai) · [Live demo](https://codesense-ai-phi.vercel.app)
DSA learning platform that runs Java and Python code and replays execution step by step.
- Traces real execution with JDI (Java) and `sys.settrace` (Python) into one common trace format
- Sandboxes user code in Docker with memory, CPU and network limits, plus rate limiting and input validation
- LLM-based code review through a provider-agnostic API, combined with rule-based checks
- GitHub Actions CI/CD to Azure and Vercel

`Java` `Spring Boot` `Docker` `Azure` `PostgreSQL`

### E-commerce platform · freelance client project (private repo)
Full-stack single-vendor store for a client.

`Java` `Spring Boot` `Next.js` `PostgreSQL`
